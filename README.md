# Пользовательская оценка защиты речи

В тестах оценивались два набора экспериментов:
- `Voice_clone`: 7 дикторов
- `Voice_clone_2`: 8 дикторов

## Этап 1
Оценка похожести оригинальной аудиозаписи и записи с незаметными для слушателя возмущениями.

## Этап 2
Оценка клонированного голоса, полученного на разных моделях синтеза речи:
- похожесть на оригинальный голос;
- естественность звучания.

В каждом проекте присутствуют оба этапа.
